## `$ whoami`

Hi, I'm **Tio Muhammad Rizky**, known on GitHub as **Foxvyn**.

I'm an Information Technology undergraduate interested in building useful software, exploring practical AI, and understanding how digital systems can be made more secure. I enjoy connecting the dots between an idea, its user experience, the engineering behind it, and the details that make it reliable.

I learn by building: exploring a problem, designing a solution, implementing it, testing the result, and improving what can be better.

<details>
<summary><strong>How I approach building</strong></summary>

- **Purpose first** — understand the problem before choosing the tools.
- **Think end-to-end** — consider usability, functionality, and security together.
- **Stay curious** — experiment with new ideas and learn from implementation.
- **Improve continuously** — refine code, workflows, and the final experience.

</details>
