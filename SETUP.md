# Foxvyn Profile — Setup & Maintenance

This folder contains the profile README, theme-aware SVG banners, and the GitHub Actions workflow for automated profile insights.

## Repository placement

Copy the contents of this folder into the root of the special profile repository named `foxvyn`:

```text
foxvyn/
├── .github/
│   └── workflows/
│       └── metrics.yml
├── README.md
├── dark.svg
├── light.svg
├── metrics-languages.svg
├── metrics-achievements.svg
└── metrics-activity.svg
```

Do not upload the outer ZIP folder itself as a nested directory. The files above must be at the repository root, except the workflow under `.github/workflows/`.

## GitHub Metrics automation

The workflow generates three smaller, independent SVGs:

- `metrics-languages.svg` — most-used languages, limited to six entries.
- `metrics-achievements.svg` — compact achievement panel, limited to eight entries.
- `metrics-activity.svg` — half-year contribution calendar.

The workflow runs daily at 00:17 UTC (07:17 WIB) and can also be started manually from **Actions → Foxvyn GitHub Metrics → Run workflow**.

### Required secret

The workflow expects the repository secret already used by the previous setup:

- Name: `METRICS_TOKEN`

Keep the token private. Do not paste it into README, workflow files, commits, or public issues. If the secret name in repository Settings → Secrets and variables → Actions is different, either rename the secret there or update `${{ secrets.METRICS_TOKEN }}` in the workflow.

### One-time setup after replacing files

1. Open the `foxvyn` profile repository.
2. Replace the existing files with the contents of this package.
3. Confirm `METRICS_TOKEN` exists in **Settings → Secrets and variables → Actions**.
4. Open the **Actions** tab and enable workflows if GitHub asks.
5. Select **Foxvyn GitHub Metrics** and click **Run workflow**.
6. Wait for the run to finish successfully.
7. Refresh the profile README. The three placeholder SVG panels will be replaced by generated metrics.

If the workflow fails, open the failed job and inspect the first red step. Common causes are a missing/expired token, insufficient token permissions, or Actions being disabled for the repository.

## Safe editing notes

- Edit personal profile facts in `README.md` and both banner SVGs together.
- The displayed tech stack is manually maintained; GitHub language metrics are generated from repository language data. They measure different things and should not be expected to match exactly.
- Featured-project descriptions are included without repository links because exact project URLs were not present in the supplied archive. Add links only after confirming the correct repositories.
- Do not add proficiency percentages, project impact numbers, employers, certificates, or achievements unless they are verified.

## Validation performed for this package

- Both banner SVGs are well-formed XML.
- The three metrics placeholders are well-formed XML and will be overwritten by the workflow.
- README references the exact SVG filenames generated by the workflow.
- Workflow retains the existing `METRICS_TOKEN` secret name.
